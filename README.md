# Beshoy Samir Younan — professional portfolio

A responsive, static portfolio in navy, slate, blue and teal. Open `index.html` directly, or serve this directory with any static web server. No installation or build is required.

## Features

- Career timeline, technical skill tiers, leadership, 12 sanitized project areas, credentials, education and contact links.
- Keyboard-accessible project filters and native expandable project/experience details.
- Dark/light themes, reduced-motion support and a print layout. Use **Print / save profile as PDF** and select your browser's Save as PDF destination.
- No database, authentication or contact backend. Cloudflare Web Analytics records aggregate traffic and performance through its public JavaScript beacon. Contact buttons open Outlook web compose drafts, with a Gmail alternative; no default desktop email handler is needed. Visitors review and send their own messages.

## Content provenance and limits

Content follows the supplied professional website brief in the referenced “Daily Job Apply” conversation. The portrait was supplied by Beshoy and is used unchanged. The original CV was not present in the retrievable reference; no CV was fabricated. The downloadable original CV can be added later, once supplied.

The referenced project list included activities requiring confirmation. Project cards therefore describe sanitized scope and contribution focus, without asserting successful incident resolutions, customer names, confidential topology or numerical outcomes. Core skills, operational support and supporting/foundational knowledge are separated conservatively; skill levels should be checked against the original CV before any public launch. Certification validity, dates and IDs are not asserted. Red Hat is labeled training, not certification.

The specific employment end date appears only within the experience timeline. The Team Manager assignment is described without changing the official job title.

## Editing

Edit content in `index.html`, presentation in `styles.css`, and theme/filter/print behavior in `script.js`. Assets are local SVGs. No secrets belong in this repository.
